# Week 2 - Day 4: STL Map, Pair & Sorting

## Objective
Learn how to use STL containers and algorithms by working with map, pair, and sorting using the `<algorithm>` header.

## Topics Covered
- STL map
- STL pair
- Key-value data storage
- Sorting with `sort()`
- `<algorithm>` header

## Activity / Practice
- Created and used a `map` to store key-value data.
- Created and used `pair` objects.
- Sorted a vector using the `sort()` function.
- Learned how `begin()` and `end()` work with STL algorithms.

## Practice Files

### 1. map-basics.cpp
- Created a map.
- Stored student IDs and names.
- Displayed map data using a loop.

### 2. pair-basics.cpp
- Created pair objects.
- Accessed values using `first` and `second`.

### 3. vector-sorting.cpp
- Sorted vector elements using `sort()`.
- Displayed sorted data using a loop.

## Hands-On Project

Updated the **Student Grade Tracker** by:
- Using `vector<Student>` to store student records.
- Using `map<int, string>` to store student IDs and names.
- Using `pair<int, string>` while inserting records into the map.
- Sorting students alphabetically using the `sort()` function.
- Displaying the Student Directory using STL containers.

## Learning Outcome

By the end of Day 4, I can:
- Use `map` to store key-value data.
- Create and use `pair` objects.
- Sort vectors using the `<algorithm>` library.
- Apply STL containers and algorithms in a real-world C++ project.
