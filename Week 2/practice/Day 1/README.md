# Week 2 - Day 1: Classes, Objects, Constructors & Access Specifiers

## Objective
Learn the fundamentals of Object-Oriented Programming (OOP) in C++ by creating classes and objects, using constructors, and understanding access specifiers.

## Topics Covered
- Classes
- Objects
- Data Members
- Member Functions
- Constructors
- Access Specifiers (`public` and `private`)

## Practice Files

### 1. classes-objects.cpp
- Created a `Student` class.
- Created an object of the class.
- Assigned values to data members.
- Displayed student information.

### 2. constructors.cpp
- Learned about constructors.
- Used a default constructor to initialize object data.
- Observed that constructors are called automatically when an object is created.

### 3. access-specifiers.cpp
- Learned the difference between `public` and `private`.
- Used setter functions to access private data.
- Displayed object information using a public member function.

### 4. student-class.cpp
- Combined all Day 1 concepts into a simple Student class.
- Took user input.
- Displayed student details.

## Learning Outcome
By the end of Day 1, I can:
- Create classes and objects.
- Use constructors for object initialization.
- Understand the purpose of access specifiers.
- Apply basic OOP concepts in a simple C++ program.
