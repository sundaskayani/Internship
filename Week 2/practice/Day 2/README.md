# Week 2 - Day 2: Encapsulation, Inheritance & Basic Polymorphism

## Objective
Learn the core Object-Oriented Programming (OOP) concepts by implementing encapsulation, inheritance, and basic polymorphism in C++.

## Topics Covered
- Encapsulation
- Inheritance
- Basic Polymorphism

## Activity / Practice
- Create a base class (`Student`).
- Create one derived class (`PremiumStudent`) to understand inheritance and basic polymorphism.

## Practice Files

### 1. encapsulation.cpp
- Implemented encapsulation using private data members.
- Used getter and setter functions to access and modify data safely.

### 2. inheritance.cpp
- Created a base class `Student`.
- Created a derived class `PremiumStudent`.
- Demonstrated how a derived class inherits properties and functions from the base class.

### 3. polymorphism.cpp
- Implemented a virtual function in the base class.
- Overrode the function in the derived class.
- Demonstrated basic runtime polymorphism.

## Hands-On Project
Continue extending the **OOP Student Grade Tracker** by:
- Using `Student` as the base class.
- Creating `PremiumStudent` as a derived class.
- Applying encapsulation and basic polymorphism in the project.

## Learning Outcome
By the end of Day 2, I can:
- Apply encapsulation using access specifiers and getter/setter functions.
- Create a base class and derived class using inheritance.
- Understand and implement basic polymorphism using virtual functions and function overriding.
- Prepare the Student Grade Tracker for further enhancements in the upcoming days.
