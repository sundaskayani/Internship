# Week 2 - Day 3: Introduction to STL - Vector

## Objective
Learn the basics of the C++ Standard Template Library (STL) by using vectors and replacing fixed-size arrays with dynamic vectors.

## Topics Covered
- Introduction to STL
- Vector
- Basic Vector Operations
- push_back()
- Vector Iteration

## Activity / Practice
- Create and use vectors.
- Add elements using `push_back()`.
- Access vector elements using indexing.
- Iterate through vectors using loops.
- Replace arrays from the Student Grade Tracker with `vector<Student>`.

## Practice Files

### 1. vector-basics.cpp
- Created and initialized vectors.
- Accessed vector elements using indexing.
- Learned how to use the `size()` function.

### 2. push-back.cpp
- Added elements dynamically using `push_back()`.
- Stored multiple values in a vector.

### 3. vector-iteration.cpp
- Displayed vector elements using a `for` loop.
- Practiced iterating through vectors using the `size()` function.

## Hands-On Project
Updated the **Student Grade Tracker** by:
- Replacing the student array with `vector<Student>`.
- Removing the fixed-size array limitation.
- Using `push_back()` to add new students.
- Using `empty()` to check whether the vector contains data.
- Using `size()` and loops to display all student records.

## Learning Outcome
By the end of Day 3, I can:
- Understand the basics of the C++ Standard Template Library (STL).
- Create and use vectors to store data dynamically.
- Add elements using `push_back()`.
- Access and iterate through vector elements.
- Replace fixed-size arrays with vectors in a real-world project.
