# Day 3 – Arrays & Strings

## Objective

Learn how to use arrays, C-style strings, std::string, and two-dimensional arrays in C++.

## Topics Covered

- Arrays
- C-style Strings
- std::string
- Two-Dimensional Arrays

## Practice Files

- arrays.cpp
- c-style-strings.cpp
- std-string.cpp
- two-dimensional-arrays.cpp

## Hands-On Task

Update the Student Grade Tracker to store multiple student names and grades using arrays.

## Learning Outcomes

- Created and accessed arrays.
- Used C-style strings.
- Worked with std::string.
- Learned how two-dimensional arrays work.
- Stored multiple student records using arrays.
