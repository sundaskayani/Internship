# Day 5 – Structs & File Basics

## Objective

Learn how to use structures to organize related data and understand the basics of file handling in C++.

## Topics Covered

- Structs
- File Writing
- File Reading
- Review and Recap

## Practice Files

- structs.cpp
- file-write.cpp
- file-read.cpp

## Hands-On Task

Refactor the Student Grade Tracker using structs and functions.

## Learning Outcomes

- Created and used structures.
- Wrote data to a file.
- Read data from a file.
- Improved the Student Grade Tracker by replacing separate arrays with a struct.
