# Day 2 – Functions

## Objective

Learn how to create and use functions in C++. Understand parameters, return types, function overloading, and default arguments. Refactor previous code into reusable functions.

## Topics Covered

- Functions
- Function Parameters
- Return Types
- Function Overloading
- Default Arguments

## Practice Files

- functions-basics.cpp
- function-parameters.cpp
- return-types.cpp
- function-overloading.cpp
- default-arguments.cpp

## Hands-On Task

Refactor the Student Grade Tracker by moving repeated code into reusable functions.

## Learning Outcomes

- Created and called custom functions.
- Passed arguments to functions.
- Returned values using return statements.
- Learned function overloading.
- Used default arguments.
- Improved code organization by refactoring into functions.
