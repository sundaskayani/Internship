This repository contains my work completed during a 6-week self-paced C++ and Frontend Development Internship. It includes practice exercises, hands-on tasks, and projects completed throughout the internship.

### Week 1 – C++ Refresher: Core Syntax & Functions
- C++ fundamentals
- Functions
- Hands-on Project: Student Grade / Expense Tracker (Console Application)

### Week 2 – Object-Oriented Programming (OOP) & STL
- Classes and Objects
- Constructors
- Encapsulation
- Standard Template Library (STL)
- Hands-on Project: Console Application using OOP and STL

### Week 3 – HTML & CSS Foundations
- HTML
- CSS
- Responsive Web Design
- Hands-on Project: Personal Portfolio Website

### Week 4 – JavaScript Fundamentals
- JavaScript Basics
- Functions
- Loops
- DOM Basics
- Hands-on Project: Interactive To-Do List / Calculator

### Week 5 – DOM & Event Handling
- DOM Manipulation
- Events
- Interactive User Interfaces

### Week 6 – Mini Project
- Build and polish a complete interactive web application
- Final project presentation
